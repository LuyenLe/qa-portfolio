SRS → Testcase v1.0

Sinh testcase Excel từ file SRS, đối chiếu & hiệu chỉnh theo ảnh chụp màn hình thật

Interface preview. This is the real Tool 06 interface running against a bundled sample SRS. Parsing a real .docx and generating the Excel testcase run on the tool’s Python/Flask backend (webapp.py, port 5055), which GitHub Pages — static hosting — cannot run. The workflow below is fully navigable; steps that need the backend are marked.

1 Chọn file SRS (.docx)

Kéo thả file vào đây, hoặc

SRS_danh_muc_dung_chung.docx

Sample SRS bundled with this preview

2 Chọn feature cần sinh testcase

Tích chọn 1 hoặc nhiều feature để sinh gộp vào 1 file (mỗi feature 1 sheet riêng). Bấm vào tên feature để xem ảnh & hiệu chỉnh field ở bước 3.

3 Đối chiếu ảnh chụp màn hình & hiệu chỉnh field

Ảnh chụp màn hình

Field — hiệu chỉnh nếu SRS khác UI thật

4 Sinh testcase

Sinh & tải file .xlsx cần backend Flask (webapp.py). Trong bản preview này nút được giữ nguyên vị trí nhưng vô hiệu hoá — chạy backend cục bộ để tạo file testcase thật.
